Summarize today's conversation and save it to Obsidian vault.

## Step 1 — Daily Note

Create or append to `~/development-personal/obsidian-vault/Daily/YYYY-MM-DD.md` (use today's date).

For each topic:

```
## [Topic Title]

**Q:** [User's question]

**A:** [Your answer, summarized concisely]
```

## Step 2 — Project Note

Create or update `~/development-personal/obsidian-vault/Projects/[ProjectName].md`.

### Commits & Changes
List commits or diffs discussed in this session.

### Implementation Summary
Use a Mermaid diagram to visualize the implemented features or data flow.

### Session Log
Brief bullet-point summary of what was discussed and decided.

---

Write all content in Korean. Commit and push the vault after saving.
