---
name: github-summary
description: "Summarize a GitHub repository. Usage: /github-summary <GitHub URL>"
---

Fetch the given GitHub repository URL and provide a concise summary:

1. **Purpose** — what the project does in one sentence
2. **Stack** — language, frameworks, key dependencies
3. **Structure** — main directories and their roles
4. **Key features** — top 3-5 notable capabilities
5. **Getting started** — install and run commands

Keep the summary under 300 words. If no URL is provided, ask for one.
